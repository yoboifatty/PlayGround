## GTA VI — Leonida Dreaming

A browser-based, third-person open-world crime sandbox built with Three.js and Vite. Play a five-mission Jason & Lucia story across a procedural Leonida: Palm Shade Motel, Ocean Beach, Port Gellhorn, and downtown Vice City.

### Run

```bash
npm install
npm run dev      # development server
npm run build    # production build in dist/
npm run preview  # preview the production build
```

### Controls

| Input | Action |
| --- | --- |
| `WASD` / arrows | Move / drive |
| Mouse | Look |
| `Shift` | Sprint |
| `E` | Interact, refuel, rob, enter interiors |
| `F` | Enter / exit vehicle |
| `X` | Swap driver and gunner seats |
| `Tab` | Switch protagonist (on foot) / swap seats (in car) |
| `Q` | Focus (bullet time, highlights threats) |
| `M` | BuckMe phone: bank, trunk, crime profile, settings |
| `T` | Open the personal car trunk |
| `Space` | Jump / handbrake |
| `R` | Reload |
| `1` `2` `3` | Pistol / SMG / shotgun |
| `Esc` | Pause |

Touch controls appear automatically on mobile, including a virtual stick, look pad, and action buttons.

### Systems

- Dynamic day/night cycle, weather, storms, wet streets, and neon lighting.
- Jason/Lucia role swapping with partner AI, driving, and gunner support.
- Vehicles with fuel, damage, repair, trunks, traffic, and carjacking.
- Weapons, focus mode, police heat, dispatch waves, witnesses, and crime profile.
- Cash/bank economy, duffel bags, fencing, deposits, and mission payouts.
- Five-mission story with waypoint HUD, rewards, and free roam after completion.
